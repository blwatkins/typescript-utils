    StaticisGenericWeightedList

    • isGenericWeightedList(input: unknown): input is WeightedList<unknown>

      Is the given input a generic WeightedList object?

      Parameters

      • input: unknown

        The input to check.

      Returns input is WeightedList<unknown>

      true if the given input is a valid WeightedList object; false otherwise. For a WeightedList to be valid, it must be a non-empty array of WeightedElement objects, where the sum of WeightedElement.weight properties in the array is equal to 1.

      Remarks

      This method does not enforce type checking for the WeightedElement.value property of the list elements.
