    • assertDenseArray(input: unknown, message?: string): asserts input is unknown[]

      Assert that input is a dense array.

      Parameters

      • input: unknown

        The input to check.

      • Optionalmessage: string

        Optional message for the error thrown when input is not a dense array.

      Returns asserts input is unknown[]

      Remarks

      A dense array has an element at every index. An array with a hole at any index, such as [1, , 3] or new Array(3), is a sparse array and is rejected. An element that is explicitly undefined is not a hole, so [undefined, 1] is a dense array. An empty array is a dense array. This method does not enforce size requirements or type checking for any array elements.
