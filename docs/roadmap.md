## About this Roadmap

This roadmap is not a frozen contract.
It is a live reflection of my current goals for the project, and it is subject to change.

## v0.1.0

- [x] String type checks and assertions
- [x] Number type checks and assertions
- [x] Deterministic random number generation
- [x] Random number selection
- [x] Random element selection
- [ ] Range type
- [ ] Generic list shuffle utility
- [ ] Random selectors
  - [ ] Range selectors
  - [ ] List selectors
  - [ ] Category/trait selectors
  - [ ] Bucket selectors

## v0.2.0

- [ ] Weighted random selectors
